# TypeBrush — User Flow Maps

This document maps the primary user journeys and navigational steps throughout the platform.

---

## 1. Primary User Flows

### Flow 1: Standard Typing Test
```
[Home /] ──► [Typing Test /typing-test] ──► [Finish Test] ──► [Results Panel]
```
- **Entry**: User visits homepage, clicks "Start Free Typing Test", inputs key coordinates, completes test, and views the detailed result.

### Flow 2: Practice My Mistakes
```
[Home /] ──► [Typing Test] ──► [Results Panel] ──► "Practice My Mistakes" ──► [Gym Workspace]
```
- **Entry**: User completes a test with errors, receives weak-key diagnostic feedback, and click the CTA to start target drills immediately.

### Flow 3: Guided Curriculum Training
```
[Home /] ──► [Typing Gym /typing-gym] ──► [Finger Placement Program] ──► [Complete Exercise] ──► [Level 2 Unlock]
```
- **Entry**: User goes to Navbar → Gym, selects standard Level 1 finger placement, finishes correct key exercises, and unlocks level 2.

### Flow 4: Certificate Generation
```
[Home /] ──► [Typing Test] ──► [Results Panel] ──► [Download Scorecard] ──► [Save A4 PDF]
```
- **Entry**: User finishes test, clicks "Print Scorecard", enters name, and generates PDF.

### Flow 5: Social Results Sharing
```
[Home /] ──► [Typing Test] ──► [Results Panel] ──► [Share Results] ──► [Clipboard Copy / Share Dialog]
```
- **Entry**: User completes test, copies formatted sharing text string.
